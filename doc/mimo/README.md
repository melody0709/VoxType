# 小米 MiMo (Xiaomi MiMo) 接入与技术文档

本文档为 VoxType 接入小米 MiMo 平台（[mimo.mi.com](https://mimo.mi.com/)）的综合技术文档与模型追踪指南。

---

## 1. 架构总览

小米 MiMo 开放平台是小米自研的大模型服务基础设施。在 VoxType 中，MiMo 同时扮演了两个关键角色：

1. **云端 ASR 识别后端（Speech-to-Text）**：
   - 接入模型：`mimo-v2.5-asr`
   - 调用协议：标准 HTTP REST POST (`multipart/form-data`)，提交 16kHz 16-bit 单声道 WAV 音频
   - 核心特点：识别准确率高、中英混合支持良好、计费门槛极低

2. **LLM 文本纠错与语义后处理（Text Refinement）**：
   - 接入模型：`mimo-v2.6-flash`（默认首选）
   - 调用协议：OpenAI 兼容的 `POST /v1/chat/completions`
   - 核心特点：高吞吐、超低时延，支持文本润色、同音字错听纠正、标点补齐

## 2. 账号体系与 Endpoint 选型

小米 MiMo 平台为开发者提供了两套不同的扣费与调用端点体系：

| 端点类型 | Base URL | 适用计费场景 | 特点与选型建议 |
| :--- | :--- | :--- | :--- |
| **Default API**（推荐默认） | `https://api.xiaomimimo.com/v1` | 按量付费（后付费 / 现金账户余额） | 适合大多数普通用户，开箱即用，按实际 Token / 音频时长计费 |
| **Token Plan (CN)** | `https://token-plan-cn.xiaomimimo.com/v1` | 资源包（国内节点抵扣） | 购买了国内折扣 Token 资源包的用户使用，国内网络时延极低 |
| **Token Plan (AMS)** | `https://token-plan-ams.xiaomimimo.com/v1` | 资源包（欧洲阿姆斯特丹节点抵扣） | 购买了海外节点资源包或海外节点专属套餐使用 |
| **Custom** | 用户自定义输入 | 内部网关 / 自建代理 / 反向代理加速 | 允许用户随时手动覆盖和微调 |

> **VoxType UI 规范实现**：
> 设置面板中提供了专门的预设下拉框（`Default API` / `Token Plan (CN)` / `Token Plan (AMS)` / `Custom`）以及宽度达到 420 DIP（右边界无缝贴合 768 DIP）的地址输入栏，既支持一键切换预设，又允许完全自由编辑。

## 3. 核心模型版本与追踪矩阵

为应对上游模型的快速迭代，VoxType 维护了统一的模型版本生命周期管理：

| 模块 | 当前接入版本 | 生产状态 | 历史弃用版本 | 下一代追踪目标 |
| :--- | :--- | :--- | :--- | :--- |
| **ASR (语音识别)** | `mimo-v2.5-asr` | **活跃 / 推荐** | 无 | 持续关注官方是否发布 `mimo-v2.6-asr` 或推出 WebSocket 双向流式协议 |
| **LLM (文本纠错)** | `mimo-v2.6-flash` | **活跃 / 推荐** | `mimo-v2.5`, `mimo-v2.5-pro`（已在 `MigrateLegacyProviderConfig` 中自动平滑迁移至 2.6 Flash） | 关注 `mimo-v3.0` 或更轻量专用微调纠错小模型 |

## 4. 关键踩坑点与工程不变量【A 级约束】

1. **LLM 深度思考模式必须关闭**：
   - **现象**：MiMo 官方接口默认开启深度思考（`"thinking":{"type":"enabled"}`），此时模型会在输出最终答案前生成一段思维链（CoT），不仅耗时激增 3~8 秒，而且官方强制将 `temperature` 锁定为 1.0。
   - **后果**：用于语音输入纠错时会出现极长等待，且高随机度容易引发改写失真或幻觉。
   - **VoxType 解决方案**：预设中强制固化 `extraParams` 为 `"thinking":{"type":"disabled"}`，以达到亚秒级响应，并恢复极低温度（0.1）的高精确纠错。
2. **ASR 必须携带完整的 RIFF WAV 标头**：
   - PCM 裸流直接上传会触发 400 校验失败，必须封装 16kHz 16bit 单声道标准 WAV 44 字节头。
3. **Endpoint 包含 `/v1` 的路径规范**：
   - ASR 端点自动补齐 `/audio/transcriptions`；LLM 端点自动拼接 `/chat/completions`。
