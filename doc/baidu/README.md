# 百度智能云语音识别 (Baidu Cloud ASR) 技术文档

本文档记录 VoxType 接入百度智能云语音识别（ASR）服务的接口协议、语言模型代码（DevPID）、Token 容错刷新机制及未来模型升级维护方案。

---

## 1. 架构总览

百度语音识别在 VoxType 中作为开箱即用、成熟稳定的云端 ASR 之一，支持通过百度智能云 API Key 和 Secret Key 换取鉴权 Token，完成音频转写。

- **调用协议**：HTTP POST REST API
- **音频格式**：16kHz 16-bit 单声道 PCM（无压缩，直接传输或封装）
- **适用场景**：方言识别（粤语、四川话）、中英混合快速转写、高稳定性保障

---

## 2. DevPID 与语种模型矩阵

百度 ASR 核心通过 `dev_pid` 决定调用哪个底层声学与语言模型：

| DevPID | 目标语种 | 特点说明 | 在 VoxType 中的配置 |
| :--- | :--- | :--- | :--- |
| **1537** | **普通话（支持简单的英文混合）** | 内置标点恢复，识别速度快，综合准确率高 | 默认推荐语种 |
| **1737** | **英语** | 适用于纯英文听写环境 | 英语专用 |
| **1637** | **粤语 (Cantonese)** | 支持粤语常用词汇与句式 | 粤语专用 |
| **1837** | **四川话 (Sichuanese)** | 支持西南官话与方言词识别 | 四川方言专用 |
| 自定义 | 用户自建专属模型 | 支持在设置中直接输入自定义 DevPID 编号 | 高级自定义 |

---

## 3. 鉴权生命周期与网络容错【A 级约束】

在 `src/asr/baidu_asr.cpp` 中固化了关键的网络容错不变量：

1. **Token 缓存与静默刷新**：
   - 使用 API Key + Secret Key 换取 `access_token`（有效期通常为 30 天）。
   - 本地自动缓存 Token；当服务端返回 Token 过期（如 Error 3302）时，自动触发清空缓存并在后台静默重新换取新 Token。
2. **【A】瞬态错误重发机制**：
   - 若遇到网络短暂断连（transient error），客户端必须保留本次录音的原始 PCM 内存切片并自动重试重发，**严禁**直接报错丢弃导致用户必须重新长按录音说第二遍。
   - 遇到鉴权失效时，刷新 Token 后同样自动附带重发当前录音帧。
